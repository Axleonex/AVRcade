# Fix one thing at a time

Open a game, then choose **Troubleshooting: start here**.

1. Choose **Check this game** if no problem has been identified yet.
2. Follow the highlighted step.
3. Finish the change, then choose **Check this game again**.

## Follow the label

| Color and label | What to do |
| --- | --- |
| Blue → Next step | Start with the highlighted action. |
| Amber ! Check needed | Read the short check before continuing. |
| Green ✓ Check passed | This check passed. A headset test is still separate. |
| Red ■ VR blocked | Resolve the blocker before trying VR. |

Colors keep the same meaning in every palette. Text labels and numbered steps also convey the meaning.

## Common fixes

**Wrong game version:** choose **Choose compatible version**. Back up saves before switching. Steam can offer older versions under **Game Versions & Betas**; availability depends on the publisher. An existing compatible copy can also be selected.

**Missing headset software:** start the software named in VR setup. Connect the headset. Check again.

**Interrupted VR update:** close the game. Choose **Repair setup**. Check again after it finishes.

**Missing original game files:** close the game. Open **More repair options**, then choose **Verify game files in Steam**. Wait for Steam to finish. Verification does not downgrade the game or fix incompatible mods.

## Need more detail?

- **Other checks** contains remaining checks.
- **Passed checks** contains successful checks.
- **Technical details** keeps the original errors, file names and instructions.
- **Full message** opens the complete status message if it does not fit in the footer.

The setup guides and version-recovery popup use the same short steps. Nothing is automatically repaired by opening help. Existing game-version, safety and installation checks still apply.
