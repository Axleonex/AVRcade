Licence texts for the third-party components shipped with AVRcade
=================================================================

AVRcade includes the components below. Each stays under its own licence; the
full text is in the named file in this folder. THIRD-PARTY-NOTICES.md, one
folder up, explains what each component is used for and lists what AVRcade
downloads on your PC instead of shipping.
